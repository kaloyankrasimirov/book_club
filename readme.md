# 📚 Django Book Club App

A web application built with Django for managing books, reviews, and user submissions. Developed as part of a Python/Django learning journey.

## 🚀 Features
* **Book Management:** View a list of books, browse individual book details, and create new book entries.
* **Review System:** Add star ratings, author details, and reviews (with spoiler tags) to books.
* **Database Integration:** Powered by PostgreSQL.
* **Form Handling:** Secure user input validation using Django forms.

## 🛠️ Tech Stack
* **Python** (v3.14)
* **Django** (v6.1+)
* **PostgreSQL**
* **HTML/CSS** (Bootstrap integration)
